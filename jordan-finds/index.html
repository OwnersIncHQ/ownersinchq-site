How we pick these Jordans

Every pair on this page is a real listing at a real retailer, with the price we saw and the date we checked it stamped right on the find. Jordan prices move faster than almost anything else we track — a pair that is one price on Monday can be gone, or re-priced, by Friday — so treat the check date as part of the deal. If this page and the retailer ever disagree, the retailer is right, and our daily pass corrects the page.

What to watch for before you buy: match the style code in the listing to the exact shoe you think you are getting — the same colorway name can cover a men's release and a grade-school release that are not the same shoe. Check which sizing the listing uses (men's, women's, or grade school) before you fall for the price, and read the retailer's own return terms on the listing, because release pairs are sometimes final-sale. We only ever link the retailer's own listing, so the price you click through to is the store's price, not a markup of ours.
